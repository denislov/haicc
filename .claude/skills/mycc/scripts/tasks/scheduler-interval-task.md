# Scheduler 支持间隔任务

> 创建时间：2026-01-31 13:00
> 状态：进行中

## 1. 需求澄清

### 背景
当前 scheduler 支持三种时间格式：
- `08:00` → 每日固定时间
- `周日 20:00` → 每周固定时间
- `2026-01-31 16:00` → 一次性任务

需要新增"间隔执行"能力，如每 30 分钟执行一次。

### 新增时间格式

| 格式 | 示例 | 含义 |
|------|------|------|
| `每Xm` 或 `每X分钟` | `每30分钟` | 每隔30分钟执行 |
| `每Xh` 或 `每X小时` | `每2小时` | 每隔2小时执行 |

### 匹配逻辑

**分钟间隔**：`当前分钟数 % 间隔 === 0`
- `每30分钟`：00:00 ✅, 00:30 ✅, 01:00 ✅, 00:15 ❌

**小时间隔**：`当前小时数 % 间隔 === 0 && 当前分钟 === 0`
- `每2小时`：00:00 ✅, 02:00 ✅, 01:00 ❌, 02:30 ❌

### 边界情况

- `每60分钟` = `每1小时`（都在整点触发）
- `每1分钟`：每分钟都触发
- 间隔必须 > 0
- 间隔必须是整数

### 任务类型

新增类型：`interval`
