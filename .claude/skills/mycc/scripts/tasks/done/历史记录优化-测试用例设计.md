# 历史记录优化 - 测试用例设计

## 需求

后端 `getConversation()` 只返回最后一个 summary 之后的消息，节省流量。

## 改动范围

- **后端**：`.claude/skills/mycc/scripts/src/history.ts`
- **前端**：不需要改（已经过滤 summary 类型）

## 测试用例

### 1. 正常场景：有 summary 的对话

**输入**：
```jsonl
{"type":"user","message":{"content":"消息1"},"timestamp":"2026-01-29T00:00:00Z"}
{"type":"assistant","message":{"content":"回复1"},"timestamp":"2026-01-29T00:01:00Z"}
{"type":"summary","summary":"前面对话的摘要","leafUuid":"uuid-2"}
{"type":"user","message":{"content":"消息2"},"timestamp":"2026-01-29T00:02:00Z"}
{"type":"assistant","message":{"content":"回复2"},"timestamp":"2026-01-29T00:03:00Z"}
```

**期望输出**：
只返回第 4-5 行（summary 之后的 2 条消息）

**验证点**：
- 消息数量 = 2
- 不包含 "消息1" 和 "回复1"
- 包含 "消息2" 和 "回复2"
- 不包含 summary 本身

---

### 2. 边界场景：没有 summary 的短对话

**输入**：
```jsonl
{"type":"user","message":{"content":"消息1"},"timestamp":"2026-01-29T00:00:00Z"}
{"type":"assistant","message":{"content":"回复1"},"timestamp":"2026-01-29T00:01:00Z"}
```

**期望输出**：
返回全部 2 条消息

**验证点**：
- 消息数量 = 2
- 包含 "消息1" 和 "回复1"

---

### 3. 边界场景：多个 summary 的超长对话

**输入**：
```jsonl
{"type":"user","message":{"content":"消息1"},"timestamp":"2026-01-29T00:00:00Z"}
{"type":"summary","summary":"摘要1","leafUuid":"uuid-1"}
{"type":"user","message":{"content":"消息2"},"timestamp":"2026-01-29T00:01:00Z"}
{"type":"summary","summary":"摘要2","leafUuid":"uuid-3"}
{"type":"user","message":{"content":"消息3"},"timestamp":"2026-01-29T00:02:00Z"}
{"type":"assistant","message":{"content":"回复3"},"timestamp":"2026-01-29T00:03:00Z"}
```

**期望输出**：
只返回最后一个 summary（第 4 行）之后的消息（第 5-6 行）

**验证点**：
- 消息数量 = 2
- 不包含 "消息1" 和 "消息2"
- 包含 "消息3" 和 "回复3"

---

### 4. 边界场景：空对话

**输入**：
```jsonl
（空文件或只有空行）
```

**期望输出**：
返回空数组或 null

**验证点**：
- 不报错
- 返回空结果

---

### 5. 边界场景：只有 summary 消息

**输入**：
```jsonl
{"type":"summary","summary":"只有摘要","leafUuid":"uuid-1"}
```

**期望输出**：
返回空数组（summary 之后没有消息）

**验证点**：
- 消息数量 = 0
- 不包含 summary 本身

---

## 测试实现方式

使用 Vitest 在 `.claude/skills/mycc/scripts/tests/history.test.ts` 中实现。

每个测试用例：
1. 创建临时 JSONL 文件
2. 调用 `getConversation()`
3. 验证返回的消息数量和内容
4. 清理临时文件
