## 1. 需求澄清

### 核心功能
将定时任务功能集成到 mycc 后端，替代原有的 bash 守护进程。

### 功能点
1. **任务解析**：读取 `tasks.md` 文件，解析三种任务类型
   - 每日任务：`HH:MM`
   - 每周任务：`周X HH:MM`
   - 一次性任务：`YYYY-MM-DD HH:MM`

2. **时间匹配**：判断当前时间是否匹配任务时间
   - 允许 ±2 分钟误差
   - 每分钟检查一次

3. **防重复执行**：同一任务在同一时间窗口内只执行一次
   - 锁的 key = `任务名 + 任务时间 + 日期`

4. **任务执行**：调用 `adapter.chat()` 执行任务
   - 执行失败不崩溃，记录日志
   - 一次性任务执行后自动删除

5. **历史记录**：记录执行结果到 `history.md`

### 边界情况
- tasks.md 不存在 → 静默跳过
- tasks.md 解析失败 → 记录日志，不崩溃
- adapter.chat() 失败 → 记录"执行失败"，继续运行
- 时间格式无效 → 跳过该行

### 技术约束
- 跨平台：macOS / Linux / Windows
- 复用 adapter 层，不重复实现跨平台逻辑
