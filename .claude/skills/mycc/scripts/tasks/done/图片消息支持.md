# 图片消息支持

> 创建时间：2026-01-28 21:07
> 状态：待验收

## 1. 需求澄清

根据 API 文档（`2-Projects/P08-cc小程序/开发文档/API文档.md`），后端 `/chat` 接口需要支持图文混合消息。

**请求格式**：
```json
{
  "message": "帮我分析这张图",
  "sessionId": "可选",
  "images": [
    {
      "data": "base64编码的图片数据（不含 data:image/xxx;base64, 前缀）",
      "mediaType": "image/png"
    }
  ]
}
```

**限制**：
| 限制项 | 值 |
|--------|-----|
| 单次最大图片数 | 1 张 |
| 单张最大大小 | 4MB（base64 解码后，即原图大小） |
| 支持格式 | PNG、JPEG、WEBP（大小写不敏感，支持 jpg 别名） |

**错误码**：
- 400：图片数量超限、图片数据为空、无效 base64
- 413：图片太大（超过 4MB）
- 415：不支持的图片格式

**边界情况**：
- 如果只发图片没有文本，用默认提示语："请分析这张图片"
- images 数组为空、undefined、null，按纯文本处理
